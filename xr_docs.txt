<p>Augmented experiences for audio glasses and display glasses are built on the
existing Android <a href="/guide/components/activities/intro-activities"><code translate="no" dir="ltr">Activity</code> framework API</a> and <a href="/develop/xr/jetpack-xr-sdk/glasses/support-different-types#activity-lifecycle">include additional
concepts</a> to support the unique aspects of these glasses. Unlike XR headsets
that run a full APK on the device, audio glasses and display glasses use a
dedicated activity that runs within your phone&#39;s existing app. This activity is
projected from the host device to the glasses.</p>

<p>To create your app&#39;s experience for audio glasses and display glasses, you
extend your existing phone app by creating a new projected <a href="/reference/kotlin/android/app/Activity"><code translate="no" dir="ltr">Activity</code></a>. This
activity serves as the main launch entry point for your app on the glasses. This
approach simplifies development because you can share and reuse business logic
between your phone and glasses experiences.</p>

<h3 id="key-points-declare-activity" data-text="Key points about the code" tabindex="-1">Key points about the code</h3>

<ul>
<li>Specifies <code translate="no" dir="ltr">android.hardware.display.category.XR_PROJECTED</code> for
the <code translate="no" dir="ltr">android:requiredDisplayCategory</code> attribute
to tell the system that this is a projected activity and can be projected
onto audio and display glasses.</li>
<li><code translate="no" dir="ltr">android.intent.action.MAIN</code> sets this activity as the default launch
activity.</li>
<li><p><code translate="no" dir="ltr">android.intent.category.XR_PROJECTED_LAUNCHER</code> is a specialized category
that makes your projected activity discoverable by Gemini voice commands.</p>

<p>When a user issues a voice command using the app&#39;s name (for example, &quot;Open
the AI catalog sample&quot;, &quot;Launch the AI catalog sample&quot;, or &quot;Start the AI
catalog sample&quot;), the system uses this category to locate and start the
designated activity on the audio or display glasses.</p></li>
</ul>
<aside class="note"><strong>Note:</strong><span> If multiple projected activities are defined with this category, Gemini
selects the first one found in the manifest file.</span></aside>

<h3 id="key-points-create-activity" data-text="Key points about the code" tabindex="-1">Key points about the code</h3>

<ul>
<li>Opts in to using <a href="/reference/kotlin/androidx/annotation/RequiresOptIn">opt-in APIs</a> from the <a href="/jetpack/androidx/releases/xr-projected">Jetpack Projected</a>
library.</li>
<li><code translate="no" dir="ltr">GlassesMainActivity</code> extends <a href="/reference/kotlin/androidx/activity/ComponentActivity"><code translate="no" dir="ltr">ComponentActivity</code></a>, just as you would
expect in mobile development.</li>
<li>Because not all glasses have a display, checks whether the device has a
display using <a href="/reference/kotlin/androidx/xr/projected/ProjectedDeviceController"><code translate="no" dir="ltr">ProjectedDeviceController</code></a>.</li>
<li>The <code translate="no" dir="ltr">setContent</code> block within the <code translate="no" dir="ltr">onCreate</code> function defines the root of
the Composable UI tree for the activity. You&#39;ll implement the <code translate="no" dir="ltr">HomeScreen</code>
composable using <a href="/develop/xr/jetpack-xr-sdk/jetpack-compose-glimmer">Jetpack Compose Glimmer</a>.</li>
<li>Initializes the UI during the activity&#39;s <a href="/reference/kotlin/android/app/Activity#onCreate(android.os.Bundle)"><code translate="no" dir="ltr">onCreate</code></a> method (see
<a href="/develop/xr/jetpack-xr-sdk/glasses/support-different-types#activity-lifecycle">projected activity lifecycle</a>).</li>
<li>To prepare for camera-related features that
<a href="/develop/xr/jetpack-xr-sdk/access-hardware-projected-context">access the glasses hardware</a>, <a href="/develop/xr/jetpack-xr-sdk/request-hardware-permissions">requests hardware permissions</a> by
registering a permissions launcher, defining the <code translate="no" dir="ltr">hasCameraPermission</code> and
<code translate="no" dir="ltr">requestHardwarePermissions</code> functions, and checking whether permissions
have been granted before calling <code translate="no" dir="ltr">initializeGlassesFeatures</code>.</li>
</ul>

<h3 id="key-points-implement-composable" data-text="Key points about the code" tabindex="-1">Key points about the code</h3>

<ul>
<li>As you defined in your activity earlier, the <code translate="no" dir="ltr">HomeScreen</code> function includes
the composable content that the user sees when the glasses&#39; display is
on.</li>
<li>The Jetpack Compose Glimmer <a href="/reference/kotlin/androidx/xr/glimmer/package-summary#Text(kotlin.String,androidx.compose.ui.Modifier,androidx.compose.ui.graphics.Color,androidx.compose.ui.unit.TextUnit,androidx.compose.ui.text.font.FontStyle,androidx.compose.ui.text.font.FontWeight,androidx.compose.ui.text.font.FontFamily,androidx.compose.ui.unit.TextUnit,androidx.compose.ui.text.style.TextDecoration,androidx.compose.ui.text.style.TextAlign,androidx.compose.ui.unit.TextUnit,androidx.compose.ui.text.style.TextOverflow,kotlin.Boolean,kotlin.Int,kotlin.Int,kotlin.Function1,androidx.compose.foundation.text.TextAutoSize,androidx.compose.ui.text.TextStyle)"><code translate="no" dir="ltr">Text</code></a> component displays the text &quot;Hello,
AI Glasses!&quot; to the glasses&#39; display.</li>
<li>The Jetpack Compose Glimmer <code translate="no" dir="ltr">Button</code> closes the activity by calling
<code translate="no" dir="ltr">finish()</code> through <code translate="no" dir="ltr">onClose</code> in the projected activity.</li>
</ul>
<aside class="note"><strong>Note:</strong><span> For an example of developing for a displayless experience, see <a href="/develop/xr/jetpack-xr-sdk/asr">Handle
audio input using Automatic Speech Recognition</a> and <a href="/develop/xr/jetpack-xr-sdk/tts">Handle audio input
using Text to Speech</a>.</span></aside>
<h2 id="check-for-glasses" class="numbered" data-text="Check whether audio or display glasses are connected" tabindex="-1">Check whether audio or display glasses are connected</h2>

<p>To determine whether a user&#39;s audio or display glasses are connected to their
phone before launching your activity, use the
<a href="/reference/kotlin/androidx/xr/projected/ProjectedContext#isProjectedDeviceConnected(android.content.Context,kotlin.coroutines.CoroutineContext)"><code translate="no" dir="ltr">ProjectedContext.isProjectedDeviceConnected</code></a> method. This method
returns a <code translate="no" dir="ltr">Flow&lt;Boolean&gt;</code> that your app can observe to get real-time updates on
the connection status.</p>
